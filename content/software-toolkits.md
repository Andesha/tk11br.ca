## My List

- **[Ghostty](https://ghostty.org/)**: Fast terminal, and very extendable.
- **[VS Code](https://code.visualstudio.com/)**: Good default editor layer for coding, search, and project navigation.
- **[pi coding agent](https://pi.dev/)**: Practical coding-agent harness for real project work.
- **[Obsidian](https://obsidian.md/)**: Useful for notes, checklists, drafts, and working context.
- **[Git](https://git-scm.com/)**: Classic version control.
  - **[glab](https://gitlab.com/gitlab-org/cli)** and **[gh](https://cli.github.com/)**: Command line access to GitHub or GitLab if you need it.
- **[ripgrep](https://github.com/BurntSushi/ripgrep)**: Fast recursive search across codebases and notes. Agents use it.
- **[curl](https://curl.se/)** and **[wget](https://www.gnu.org/software/wget/)**: Essential that's somehow not in build-essential.
- **[cmake](https://cmake.org/)** and **[build-essential](https://packages.ubuntu.com/search?keywords=build-essential)**: One time runs for when the system is fresh.
- **[uv](https://docs.astral.sh/uv/)**: Fast Python package and environment management.
- **[htop](https://htop.dev/)**: Quickly view what processes are doing.
- **[rsync](https://rsync.samba.org/)**: More powerful scp tool.
- **[sshfs](https://github.com/libfuse/sshfs)**: Mount remote filesystem.
- **[ffmpeg](https://ffmpeg.org/)**: Solves a surprising number of recording and media-conversion problems.
- **[Docker](https://www.docker.com/)**: Useful for containers, reproducibility, and local service setup.
- **[FileZilla](https://filezilla-project.org/)**: Useful when a graphical SFTP client is the easiest path.
- **[RustDesk](https://rustdesk.com/)**: Practical remote support tool.
- **[Tailscale](https://tailscale.com/)**: Low-friction private networking between machines.
- **[Mullvad VPN](https://mullvad.net/)** and **[Cloudflare WARP](https://one.one.one.one/)**: Handy for privacy, travel, and awkward network situations.
- **[OBS Studio](https://obsproject.com/)**: Great for demos, talks, and screen recordings.
- **[VLC](https://www.videolan.org/vlc/)**: Reliable player for ordinary and weird media files.
